NOIR — сайт студии пирсинга

Файлы проекта:
- index.html — главная страница сайта (GitHub Pages открывает её автоматически)
- piercing.html — та же главная страница под прежним адресом
- services.html, jewelry.html, care.html, about.html, booking.html — внутренние страницы
- style.css — оформление
- script.js — меню, анимации и демонстрационная форма
- images/ — исходные фотографии проекта

Как опубликовать:
1. Открой репозиторий https://github.com/nnothingnessdd/noir-piercing
2. Нажми Add file → Upload files.
3. Распакуй этот архив на компьютере и перетащи ВСЁ содержимое папки noir-piercing-ready (не саму папку) в окно загрузки GitHub.
4. Нажми Commit changes.
5. В репозитории открой Settings → Pages, выбери Deploy from a branch, ветку main и папку /(root), затем Save.

После публикации ссылка будет примерно такой:
https://nnothingnessdd.github.io/noir-piercing/

Важно: форма записи пока демонстрационная и не отправляет заявки. Перед реальным использованием подключи сервис записи или форму отправки.
